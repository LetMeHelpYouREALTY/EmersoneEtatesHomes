
# Emerson Estates Website

A luxury real estate website for Emerson Estates, featuring premium homes in Las Vegas, Nevada.

## 🏠 About

**Domain:** www.emersonestateshomes.com  
**Address:** 2583 Regency Cove Ct, Las Vegas, NV 89121  
**Type:** Luxury Real Estate Website

Emerson Estates offers elegant residences with modern amenities and stunning desert views in one of Las Vegas' most prestigious communities.

## 🚀 Features

- **Responsive Design:** Mobile-friendly layout optimized for all devices
- **Property Listings:** Integrated RealScout widget for property search
- **SEO Optimized:** Meta tags, structured data, and clean URLs
- **Contact System:** Lead capture with API integration
- **Modern UI:** Clean, professional styling with Tailwind CSS

## 🛠️ Tech Stack

- **Framework:** Next.js 15.2.3 with TypeScript
- **Styling:** Tailwind CSS 4.0 + CSS Modules
- **Deployment:** Replit Deployments
- **Property Data:** RealScout API integration

## 📦 Installation

1. **Clone the repository** (if using version control)
2. **Install dependencies:**
   ```bash
   npm install
   ```
3. **Start development server:**
   ```bash
   npm run dev
   ```
4. **Visit:** http://localhost:3000

## 🎯 Available Scripts

```bash
# Development server
npm run dev

# Production build
npm run build

# Start production server
npm run start

# Lint code
npm run lint
```
